# JavaScript-2-CA

CA for the JavaScript-2 course. Application consisting of ability to create, read, update and delete social posts from the Noroff API.

## Description

Social media page using the noroff-API with the following features:

- Register new profile
- Login existing profile
- See a feed of all posts from the api
- View your own profile with all your posts
- Search for, and view others profiles, including all their posts
- Search and view specific posts based on their content
- Create new posts
- Edit previous posts
- Delete previous posts
